# Scoundrel: A 44 Card Dungeon Crawl

Being the germ of an implementation of the dungeon crawl solitaire game
designed by Zach Gage and Kurt Bieg. The rules are available as a
[pdf from Zach's website](http://stfj.net/index2.php?year=2011&project=art/2011/Scoundrel.pdf),
and there's a [really nice explanatory video on YouTube](https://www.youtube.com/watch?v=7fP-QLtWQZs)

## The State Of Affairs

As mentioned, this is at a very early stage, and can basically only
shuffle cards at this point, and doesn't even have any kind of interface,
but that will hopefully change soon...
